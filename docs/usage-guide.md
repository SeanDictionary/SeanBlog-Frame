## 1. 登录与认证

### 1.1 登录

- 地址：`/login`（如 `https://your-domain/login`）。
- 登录页为居中卡片，含「返回网站」链接、用户名与密码两个输入框、登录按钮。
- 用户名输入框默认填 `admin`。系统**只接受 `admin`** 这一个管理员账户（单管理员模式）。
- 登录成功后跳转到 `/admin`（后台仪表盘）。
- 错误提示：
  - 「用户名或密码不正确」—— 凭据错误。
  - 「服务暂时不可用，请稍后重试」—— 数据库不可达，**不是密码问题**，请稍后再试或检查数据库连接。

### 1.2 会话与登出

- 会话基于 JWT，有效期 **7 天**；活跃用户每 24 小时自动续签，连续空闲超过 7 天自动登出。
- 登出入口在后台侧边栏底部的「退出」按钮。
- 重置管理员密码后，所有旧会话最多在 **30 秒内失效**（因有 30s 进程内版本缓存）。

### 1.3 管理员密码

- **首次创建**：部署时由 `scripts/initialize-admin.mjs` 创建 `admin` 账户并打印一次性明文密码（Docker 部署可从 app 容器日志 `grep` 获取）。
- **忘记密码 / 重置**：在服务器上运行 `npm run admin:reset-password`（对应 `scripts/reset-admin-password.mjs`）。脚本会生成新密码并打印，同时令所有旧会话立即失效。
  - 新密码用 `randomBytes(24).toString('base64url')` 生成，bcrypt cost 12 存储，**仅显示一次，请妥善保存**。

> 登录失败会触发限流并记录到操作日志；连续失败请稍后再试。

## 2. 后台仪表盘

路径：`/admin`（即后台首页）。顶部有「新建文章」按钮。

### 2.1 概览区

- **四张统计卡片**：
  | 卡片 | 含义 | 点击跳转 |
  |---|---|---|
  | 草稿 | 草稿状态文章数 | `/admin/articles?status=DRAFT` |
  | 全部文章 | 所有文章数 | `/admin/articles` |
  | 评论 | 评论总数（若开启人工审核，副标题显示待审核条数） | `/admin/comments` |
  | 总访问量 | 全站累计访问量（副标题显示访问人数） | `/admin/overview` |
- **文章热度 Top 6**：按浏览量倒序，带热度进度条，点击进入编辑页。
- **最近评论**：最新 5 条，带状态徽章（已通过 / 待审核 / 垃圾 / 已删除）。
- **近 30 天访问趋势**：折线图，含访问量、访问量不含爬虫、访客数三条线。
- **洞察项**：30 天访问量、30 天访客数、日均访问量、高峰时段、最多来源地区 / 操作系统 / 浏览器 / 来源 URL。

### 2.2 侧边栏导航

从上到下：概览、文章、分类标签（分类、标签）、评论、统计（总览、访问记录、访客记录）、主题、媒体、日志、设置。底部显示管理员身份、「退出」按钮、站点名、版本号（可点「检查更新」）、「查看网站」链接。

> 移动端宽度 ≤ 767px 时侧边栏自动折叠。

## 3. 文章管理

### 3.1 文章列表

路径：`/admin/articles`。

- **筛选**：状态（草稿 / 已发布 / 已归档）、分类、标签、关键词搜索（匹配标题、正文、标签、分类，350ms 防抖）。
- **排序**：点表头切换，支持更新时间、发布时间、创建时间、浏览量、访客数、标题（标题默认升序，其余默认降序）。
- **列**：标题 + slug（可新窗口打开前台）、状态徽章（含置顶、待发布标记）、分类 / 标签（点击带 slug 过滤）、浏览量、浏览人数、发布时间、更新时间。
- **分页**：7 段式带省略号，每页可选 20 / 50 / 100。
- **批量操作**（选中后）：批量发布、设为草稿、批量归档、批量删除（确认）、导出 ZIP、导入 ZIP。

### 3.2 新建与编辑

- 新建：`/admin/articles/new`；编辑：`/admin/articles/:id/edit`。
- 编辑器顶部按钮：**编辑 / 预览**切换、**保存草稿**（状态置草稿）、**发布文章**（新建时直接发布）/ **保存文章**（编辑时保持原状态）。

编辑器内的重要交互：

- **本地自动草稿**：每 900ms 自动存到浏览器 localStorage（key `seanblog:article-draft:{id|new}`）。打开时若本地草稿比服务器新，会提示恢复或忽略。
- **离开保护**：有未保存改动时，关闭 / 跳转 / 刷新会弹出确认。
- **Slug 自动生成**：标题输入时自动用拼音生成 slug；一旦手动改过 slug 就停止自动覆盖。slug 实时校验唯一性。
- **图片粘贴**：在正文区粘贴图片自动上传到媒体库并插入 Markdown；头图输入框粘贴图片同样上传。
- **预览**：切换到预览模式时实时渲染（调预览 API，使用当前主题的样式）。

## 4. 正文写作：Markdown 与特殊卡片

文章正文使用 Markdown，由统一的 remark + rehype 管线渲染。除标准 Markdown / GFM 外，平台提供 **3 类特殊卡片** 和若干增强块。**这些语法是平台内置的，与主题无关**——任何主题都会得到相同的 HTML 结构，只是外观样式由主题决定。

### 4.1 Callout 提示框

用于在正文中插入带配色的提示 / 警示框。有两种等价写法：

**指令写法（推荐）**：

```
:::note
这是一条补充说明。
:::

:::warning
这是一条潜在风险提示。
:::
```

**GitHub Admonition 写法**（用引用块）：

```
> [!NOTE]
这是一条补充说明。

> [!IMPORTANT]
这是一条强调内容。
```

支持的 5 种命名类型：

| 类型 | 语义 | 配色 |
|---|---|---|
| `note` | 补充说明、背景信息 | 主题强调色 |
| `tip` | 建议、最佳实践 | 绿 |
| `important` | 强调 | 紫 |
| `warning` | 潜在风险 | 警告色 |
| `caution` | 不可逆 / 破坏性强警示 | 错误色（红） |

GitHub 写法的大小写映射：`NOTE`→`note`、`TIP`→`tip`、`IMPORTANT`→`important`、`WARNING`→`warning`、`CAUTION`→`caution`。**大小写敏感**：`:::NOTE` 或 `[!note]` 不识别。

**自定义类型**（逃生口，需主题 / 后台 CSS 自配配色，否则回退灰色边框）：

```
:::callout{type=自定义名}
内容
:::

:::callout{.warning}        也可用 className
内容
:::
```

产出 `<div class="callout callout--{type}">`。Callout 是唯一有平台兜底样式的卡片——内置默认 CSS，且管理员可在后台「主题 > Callout CSS」自定义外观（见 [§11.3](#113-callout-css-编辑)）。

### 4.2 github-repo 仓库卡片

在正文中插入一个 GitHub 仓库卡片，自动拉取仓库信息（描述、语言、Star、Fork），服务端缓存 1 小时。

```
:::github-repo{author="solstice23" project="argon-theme" size="full"}
:::github-repo{repo="solstice23/argon-theme"}            简写
:::github-repo{author="..." project="..." size="mini"}   mini 变体
```

- 必填：`author` + `project`，或用 `repo="owner/name"` 简写。
- 可选：`size` = `full`（默认，显示描述 / 语言 / Star / Fork）或 `mini`（精简，仅显示标题与 Star）。
- 拉取失败时显示错误态卡片，不会让页面报错。

> 建议在生产环境配置 `GITHUB_TOKEN` 环境变量以提升 API 速率限制。未配置时走匿名请求，高频拉取可能触发限流（但有 1 小时缓存兜底）。

### 4.3 friend-link 友链卡片

插入一张友链卡片。连续多个友链卡片会自动排列成多列网格。

```
:::friend-link{name="站点名" url="https://example.com" avatar="https://example.com/logo.png" desc="一句描述"}
```

- 必填：`name` + `url`。
- 可选：`avatar`（不填则用站点名首字母圆圈占位）、`desc`。

### 4.4 代码块（Shiki 双主题高亮）

用围栏代码块，指定语言即获得语法高亮（浅色 `github-light`、深色 `github-dark` 自动切换）：

````markdown
```js
const x = 1
```
````

- 代码块左上角会显示语言标签（由主题 CSS 渲染）。
- `sage` 作为 `python` 的别名。
- 未指定语言默认按 `text` 处理。
- 高亮基础样式由平台内置兜底，主题可覆盖。

### 4.5 数学公式（KaTeX）

- 行内：`$E = mc^2$`
- 块级：

```
$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$
```

仅当文章包含公式时，页面才会加载 KaTeX 样式（CDN），无公式不加载。

### 4.6 GFM（GitHub 风格 Markdown）

由 `remark-gfm` 提供：表格、任务列表（`- [ ]` / `- [x]`）、删除线（`~~文本~~`）、自动链接。

### 4.7 标题与目录

正文 h2–h4 会自动生成 slug 化 `id`（同名追加序号去重），供锚点跳转。主题可在文章页渲染目录（TOC）。

### 4.8 原始 HTML（白名单净化）

正文可内嵌原始 HTML，经 `rehype-raw` + `rehype-sanitize` 净化。白名单额外允许 `div`、`span`、`figure`、`figcaption`、`iframe`、`details`、`summary` 等。

- 可用 `<details><summary>` 做可折叠块、`<iframe>` 嵌入视频。
- `iframe.src` 仅限 `http` / `https`（禁止 `data:`）。
- `script`、`style` 标签**不允许**；`className`、`style`、`data-*` 属性允许。

### 4.9 不支持的卡片类型

平台**没有** `code-group`、`gallery`、`embed`、`image-card`、`bookmark` 等类型。需要折叠代码请用 `<details>`，需要嵌入视频请用 `<iframe>`。

## 5. 文章字段详解

编辑器中的所有可填字段：

| 字段 | 用途 | 必填 | 默认 / 限制 |
|---|---|---|---|
| 标题 `title` | 文章标题 | 是 | ≤ 200 字符 |
| Slug `slug` | URL 别名 | 是（自动生成，可手改） | ≤ 120，正则 `^[a-z0-9]+(?:-[a-z0-9]+)*$`，实时校验唯一 |
| 摘要 `excerpt` | 列表 / RSS / SEO 描述 | 否 | 不填则由正文取前 200 字符自动生成 |
| 正文 `contentMarkdown` | Markdown 正文 | 是 | — |
| 头图 `coverImage` | 文章头图 URL | 否 | 填 URL 或粘贴图片（png/jpg/jpeg/gif/webp）；≤ 2048，需 http(s) 或站内 `/uploads` 路径 |
| 状态 `status` | 草稿 / 已发布 / 已归档 | 是 | 新建默认草稿 |
| 评论模式 `commentsMode` | 允许 / 只读 / 关闭 | 是 | 默认 `enabled` |
| 置顶 `isPinned` | 列表置顶 | 否 | 默认否 |
| 页面 `isPage` | 文章 / 页面 | 否 | 默认文章；页面不在公开文章列表显示 |
| 定时发布 `publishedAt` | 配合「定时发布」开关 | 否 | 开启后必填且须晚于当前时间 |
| 分类 `categoryId` | 单选 | 否 | 默认「未分类」；支持保存时新建 |
| 标签 `tagIds` | 多选 | 否 | 可选已有或输入新建 |
| SEO 标题 `metaTitle` | 覆盖 `<title>` | 否 | — |
| SEO 描述 `metaDescription` | 覆盖 meta description | 否 | — |
| 关键词 `metaKeywords` | meta keywords | 否 | — |

> 文章与页面的区别仅在于 `isPage` 标记。页面不会出现在公开文章列表，适合「关于」「友链」等独立页。

## 6. 状态、定时发布与修订历史

### 6.1 状态流转

三个状态：**草稿 ⇄ 已发布 ⇄ 已归档**。

- 发布：状态置「已发布」，`publishedAt` 设为当前时间（或指定时间）。
- 设为草稿：`publishedAt` 清空。
- 归档：状态置「已归档」，`publishedAt` 清空，前台不再可见。
- 列表中「待发布」徽章表示 `publishedAt` 晚于当前时间（定时发布中）。

### 6.2 定时发布

编辑器勾选「定时发布」后，填写 `publishedAt`（须晚于当前时间）。保存为已发布状态后，文章会在到达 `publishedAt` 时刻自动对前台可见（前台查询过滤 `publishedAt <= now`）。

> 注意：定时发布依赖前台查询时的 `publishedAt` 比较，并非后台 cron 主动改状态。列表中会显示「待发布」徽章。

### 6.3 修订历史

- 每次正文内容变更保存时自动创建一个新版本（版本号递增），写入修订记录与修订 Markdown 文件。
- 新建文章保存时创建初始版本（说明 `Initial version`）。
- 编辑器右侧「版本管理」面板列出所有版本，每条显示时间与变更说明。
- 点「恢复」会拉取该版本内容覆盖当前标题与正文（**不会自动保存**，需手动点保存）。

## 7. 文章 ZIP 导入导出

用于文章迁移、备份、批量操作。入口在文章列表页的批量操作区。

### 7.1 导出 ZIP

- 选中文章后点「导出 ZIP」，下载一个 zip 文件。
- 单次导出上限 **100 篇**。
- 结构：每篇文章一个目录（单篇则根目录为空），含 `article.json`（元数据）+ `article.md`（正文）+ 媒体文件（`image/cover.*`、`image/article/*`）。
- 正文内站内媒体（`/uploads/...`）会被改写为 zip 内相对路径 `image/article/...`，封面图改写为 `image/cover.*`，保证导出包自包含。

### 7.2 导入 ZIP

- 点「导入 ZIP」上传一个 zip 文件。
- 限制：最大 800 个条目、压缩 ≤ 25MB、未压缩 ≤ 80MB、单文件 ≤ 10MB。
- 自动忽略 `__MACOSX`、`.` 开头的路径。
- 每篇须含 `article.json`（必含 `title` + `slug`）与 `article.md`。
- 媒体：`image/article/*` 必须被正文引用；支持 avif/gif/jpg/jpeg/png/webp；封面 `image/cover.*`（不能与外部 `coverImage` URL 共存）。
- 冲突按 `slug` 处理；已存在的 `id` 会被跳过（返回 `skippedIds`）。
- 导入按事务执行，失败回滚已创建文章与媒体目录。

## 8. 分类与标签

路径：分类 `/admin/categories`、标签 `/admin/tags`。布局为左侧列表 + 右侧编辑面板。

### 8.1 通用操作

- 新建：右侧表单填名称、slug、描述后保存。
- 编辑：点列表项，右侧加载其数据，修改后保存。
- 删除：单条（右侧删除按钮，确认）；批量（选中后批量删除，确认）。删除分类 / 标签**不会删除文章**，文章仅失去关联。
- 导出：批量操作可导出选中项为 JSON。
- 列表项右侧「N 篇文章」链接跳转到对应筛选的文章列表。

### 8.2 字段与限制

| 字段 | 限制 |
|---|---|
| 名称 `name` | ≤ 80 字符 |
| Slug `slug` | ≤ 120，正则 `^[a-z0-9]+(?:-[a-z0-9]+)*$`，唯一；名称未手改时自动从名称生成拼音 slug，实时校验唯一性 |
| 描述 `description` | ≤ 500 字符 |

### 8.3 默认分类保护

slug 为 `uncategorized` 的默认分类**不可删除、不可编辑**（字段禁用）。系统会自动确保它存在。分类与标签均为扁平结构，**无层级 / 无合并**功能。

## 9. 评论管理与审核

路径：`/admin/comments`。

### 9.1 评论列表

- 顶部状态 tab：全部 / 待审核 / 已通过 / 垃圾 / 回收站。
- 每行显示：评论内容、作者（昵称 / 邮箱，若有 http(s) 链接则显示为外链）、关联访客 ID（截前 8 位，链接到访客详情）、所属文章 + 时间、状态徽章。
- 单条操作按钮按当前状态显示对应可用动作（通过 / 待审核 / 垃圾 / 回收站）。
- 批量操作：全选、批量通过、批量标记垃圾、批量待审核、批量移至回收站（确认）、批量删除（确认「不可撤销」）。

状态值：`PENDING`（待审核）/ `APPROVED`（已通过）/ `SPAM`（垃圾）/ `TRASHED`（回收站）。彻底删除仅出现在批量动作中。

### 9.2 文章级评论模式

每篇文章可单独设置 `commentsMode`：

| 模式 | 行为 |
|---|---|
| `enabled` 允许 | 显示已有评论，可新发评论 |
| `readOnly` 只读 | 显示已有评论，不可新发 |
| `disabled` 关闭 | 不显示评论，不可新发 |

在文章编辑器中设置。新建文章默认 `enabled`。

### 9.3 审核规则与黑名单

在评论页的「评论审核规则」面板配置（独立于站点设置）：

- **默认通过未命中评论**（`autoApprove`）：开启后，未命中黑名单的评论直接通过；关闭则进入待审核。默认关闭。
- **黑名单**（`blacklist` textarea）：换行或逗号分隔多条规则。
  - 普通文本 = 关键词包含匹配（大小写不敏感）。
  - `/pattern/flags` = 正则（flags 支持 `d/g/i/m/s/u/v/y`）。
  - 规则同时匹配评论内容、昵称、邮箱、链接拼接后的文本。
- 保存前会校验正则合法性，非法正则阻止保存。
- 当 `autoApprove` 开启且黑名单为空时，会二次确认「所有新评论都会自动通过」。

决策逻辑：命中黑名单 → 标记为垃圾；否则 `autoApprove` 开 → 通过；否则 → 待审核。

> 评论黑名单维度为关键词 / 正则（作用于评论文本）。平台**未提供**独立的 IP / UA 评论黑名单（IP / UA 是访问采集维度，可在操作日志中查看）。

## 10. 媒体库

路径：`/admin/media`。网格视图展示所有上传文件。

### 10.1 上传

三种方式：

1. 文件选择框（支持多选）。
2. 整页拖拽（拖入后出现全屏遮罩「松开鼠标以上传」）。
3. 整页粘贴（Ctrl/Cmd+V）。

上传走 `/api/admin/media/upload`，FormData 字段名 `file`，支持多文件。

### 10.2 限制与安全

- 单文件大小：1 字节 ~ **50 MB**。
- 按 MIME 分六类，每类有扩展名白名单：
  | 分类 | 扩展名 |
  |---|---|
  | 图片 | png/jpg/jpeg/gif/webp/avif/bmp/ico |
  | 视频 | mp4/webm/mov/mkv/ogv |
  | 音频 | mp3/wav/ogg/flac/aac/m4a/opus |
  | 文档 | pdf/txt/csv/md/json/xml/rtf/doc/docx/xls/xlsx/ppt/pptx/odt/ods/odp |
  | 归档 | zip/tar/gz/bz2/xz/7z/rar |
  | 其他 | 仅 pdf/txt/csv/md/json/xml |
- 危险扩展名（html/svg/js/exe/php 等）直接拒绝。
- 字节签名检测可执行文件 / 标记内容（MZ / ELF / `<!doctype` / `#!`）拒绝。
- 文件名清洗非法字符并截断到 120 字符，冲突时自动追加序号。

### 10.3 浏览与管理

- 顶部分类筛选按钮（仅显示当前页存在的分类）。
- 搜索：按文件名或路径模糊匹配（350ms 防抖）。
- 分页：20 / 50 / 100。
- 删除：单条（确认，同时删除 uploads 下本地文件）；批量（确认）。
- 点击缩略图在新窗口打开文件 URL（`/uploads/...`）。

> 媒体库暂无图片裁剪、说明（caption）字段，也无显式「复制链接」按钮——点击缩略图即可在新窗口打开并复制地址栏 URL，或在文章编辑器中通过粘贴图片自动引用。

## 11. 主题管理

路径：`/admin/themes`。

### 11.1 主题列表与切换

卡片网格展示所有已安装主题（名称、作者、版本、描述，当前启用主题高亮）。

- **启用**：点「启用」切换活动主题（默认主题不可卸载，当前主题不可重复启用）。
- **导入主题包**：选 `.zip` 上传，弹窗选择设置处理模式：
  | 模式 | 行为 |
  |---|---|
  | `ignore` 仅主题文件 | 不导入任何设置 |
  | `preserve` 保留配置（推荐） | 仅当当前无任何配置时才导入设置 |
  | `restore` 覆盖配置 | 用包内设置覆盖当前配置（危险，红框警示） |
- **更新**：对已有主题按更新模式导入，覆盖同 slug；旧设置默认保留；版本降级会警告。
- **导出**：弹窗选「仅主题文件」或「主题文件 + 全量设置快照」下载。
- **卸载**：删除主题（确认），默认主题不可删。

### 11.2 主题设置

当前主题的 `settingsSchema` 动态渲染为表单。支持控件类型：text / color / number / boolean / select / multiselect / list / range / textarea。颜色选择器含 16 色预设圆点；支持 1 层或 2 层分组（子组可折叠）；支持 `if` 条件显隐（引用其他设置项）。隐藏项不提交（服务端保留原值）。保存后前台实时反映（靠 `router.refresh`）。

### 11.3 Callout CSS 编辑

主题页内置 Callout CSS 编辑器：

- Prism 语法高亮的 textarea，实时校验 CSS 合法性（500ms 防抖），校验通过才能保存。
- 「重置为预设」恢复默认 Callout CSS。
- 保存写入当前主题设置 `calloutCustomCss`，前台 Callout 样式即按此渲染。

Callout 样式有三层兜底链：后台 `calloutCustomCss`（此处编辑）→ 主题 `assets/callout.css` → 平台内置默认。

### 11.4 主题包规范（简述）

供主题开发者参考（详见 [`theme-development.md`](theme-development.md)）：

- zip ≤ 2MB；文件数 ≤ 200；单文件 ≤ 2MB；解压总 ≤ 20MB。
- slug 须匹配目录名且 `^[a-z0-9][a-z0-9_-]{0,63}$`。
- `theme.yaml` 中 `engine` 必须是 `seanblog-theme`，`engineVersion` ≤ 2。
- Handlebars 模板在安装期预校验语法。
- CSS 中 `url()` 仅可引用包内相对资源（自动重写为 `/api/themes/:slug/asset?path=`）。

## 13. 访问分析

### 13.1 统计总览

路径：`/admin/overview`。

- 查询参数：`rangeDays`（7 / 30 / 90 / 180，默认 30）、`trendGranularity`（day / week / month，默认 day）。
- 左侧：全站访问趋势图（可切粒度）+ 最近访问记录（最新 20 条，精简表）。
- 右侧：全站访问量（按时间段统计访问量 / 访客数）、文章统计 Top 10（按访问量）、访问来源地区 Top 5、访问系统 Top 5。
- 趋势图三条线：访问量（蓝）、访问量不含爬虫（绿）、访客数（橙虚线）。悬停显示 tooltip。

### 13.2 访问记录

路径：`/admin/visits`。

- 列：访问时间、访问时长、访问内容（标题 + slug/path + 外链）、地区 / IP、系统、浏览器、来源 URL。
- 筛选：日期范围。
- 分页：20 / 50 / 100。
- 行点击弹出「访问详情」：访问时间、时长、访客 ID（链接到访客详情）、内容类型、访问内容、地区、IP、系统、浏览器、UA、来源 URL、浏览器指纹（语言 / 时区 / 屏幕宽高 / 像素比）、硬件信息（CPU 核心数 / 内存 GB / 显卡）。
- 爬虫行底色标记，详情对话框显示「爬虫访问」标签。
- 表头「地区/IP」「系统」「浏览器」「来源 URL」可点击查看字段分布统计（计数 / 合计 / 百分比，爬虫单独计数不计入合计）。
- CSV 导出：右上按钮，带当前日期筛选。

### 13.3 访客记录

路径：`/admin/visitors`。

- 列：访客 ID（截断显示，链接到详情）、首次访问、最近访问、访问次数、总时长、访问最多文章。
- 分页：20 / 50 / 100。
- CSV 导出。

### 13.4 访客详情

路径：`/admin/visitors/:visitorId`。

- 顶部统计卡：访问次数、事件数、总时长、首次访问。
- 多栏统计：文章访问统计、分类 / 标签访问统计、来源 URL 统计、浏览器指纹记录、硬件信息记录、地区统计、浏览器 / 系统统计。
- 最近访问：最近 10 条记录。

### 13.5 地区识别

地区识别依赖 ipinfo.io lite API，**需要在「设置 > 访问统计与隐私」填入 ipinfo.io 访问令牌**。留空则不查询，地区留空 / 未知。私有 / 环回 IP 直接跳过。地区查询结果缓存 6 小时（最多 10000 条）。

## 14. 操作日志

路径：`/admin/logs`。记录后台所有写操作（文章 / 评论 / 媒体 / 主题 / 设置 / 认证等模块的 create / update / delete / bulk / login / logout 等）。

- 列：时间、结果徽章、模块 / 操作、操作人（含类型）、内容（摘要 + 目标）、错误、请求（method → path）。
- 行点击查看详情：时间、结果、模块.操作、操作人、内容、目标、请求、错误、元数据 JSON。
- 分页：上一页 / 下一页。

- 保留期由「设置 > 操作日志保留天数」控制，超期用 `npm run logs:prune` 清理。

## 15. SEO 自动生成

以下内容由平台自动生成，无需手动维护，均以「站点设置」中的 `siteUrl` 为基础 URL：

- **`/sitemap.xml`**：首页（priority 1，daily）+ 所有公开文章（priority 0.8，weekly）+ 所有分类（priority 0.5）+ 所有标签（priority 0.5）。
- **`/robots.txt`**：`User-agent: *`，`Allow: /`，`Disallow: /admin/`，并指向 sitemap。
- **`/rss.xml`**：RSS 2.0，channel 取站点名 / URL / 描述，item 取最近 50 篇公开文章。

文章级 SEO：在编辑器中填写 `metaTitle`（覆盖 `<title>`）、`metaDescription`（覆盖 meta description）、`metaKeywords`。头图 `coverImage` 作为 OG 图。平台未提供独立的 canonical / ogImage 字段。

## 附录：特殊卡片语法速查表

| 卡片 | 语法 | 必填 / 可选 |
|---|---|---|
| Callout（5 种） | `:::note` … `:::`<br>`:::tip` / `:::important` / `:::warning` / `:::caution` | — |
| Callout（GitHub 写法） | `> [!NOTE]` … | `NOTE/TIP/IMPORTANT/WARNING/CAUTION` |
| Callout（自定义） | `:::callout{type=自定义名}` … `:::` | 需自配 CSS 配色 |
| GitHub 仓库卡片 | `:::github-repo{author=… project=… size=…}` | 必填 author+project；可选 size=full/mini |
| GitHub 仓库卡片（简写） | `:::github-repo{repo="owner/name"}` | 必填 repo |
| 友链卡片 | `:::friend-link{name=… url=… avatar=… desc=…}` | 必填 name+url；可选 avatar/desc |
| 代码块 | ` ```lang ` … ` ``` ` | 可选语言；`sage`≈`python` |
| 行内公式 | `$E=mc^2$` | — |
| 块级公式 | `$$` … `$$` | — |
| 任务列表 | `- [ ]` / `- [x]` | GFM |
| 删除线 | `~~文本~~` | GFM |
| 折叠块 | `<details><summary>标题</summary>…</details>` | 白名单 HTML |
| 嵌入视频 | `<iframe src="https://…"></iframe>` | src 仅限 http/https |

> 所有卡片语法由平台统一渲染产出固定 HTML 结构，外观样式由主题决定。Callout 是唯一有平台内置兜底样式的卡片，其余卡片（github-repo / friend-link）的样式完全由主题实现——换主题时若新主题未提供对应 CSS，卡片会以无样式裸结构渲染。
