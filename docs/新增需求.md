# 新增需求

[ ] Dock 栏内的搜索按钮，交互存在问题，用户点击时不要消失，而是保持不变，直接出现搜索输入框
[ ] 搜索输入框显示不在正中心位置，位置存在问题
[ ] 搜索时，显示的搜索结果支持高亮显示搜索关键字，且支持搜索结果的分页功能
[ ] 搜索时，支持通过空格或+号分隔多个关键字进行搜索
[ ] 搜索时，搜索框莫仍文本显示搜索样例

[ ] 首页文章展示需要支持头图显示，如果没有指定图片就不显示
[ ] 首页文章的摘要部分如果没有自定义摘要，则使用文章内容的前 200 个字作为摘要。
[ ] 首页文章列表需要支持分页功能，避免一次性加载过多文章。
[ ] 首页文章支持排序功能，支持按发布时间、更新时间、浏览量、评论数等字段进行排序


[ ] 文章详情页面里，文章内容显示位置不在正中心
[ ] 文章详情页面里，缺少预估阅读时间，该数据需要作为文章元数据的一部分，支持在后台设置是否显示
[ ] 文章详情页面里，缺少文章字数统计，该数据需要作为文章元数据的一部分，支持在后台设置是否显示
[ ] 文章详情页面里，缺少上一篇、下一篇文章的导航功能

[ ] 后台页面，支持侧边栏展开和缩小，缩小情况下即不显示文字用图标代替

[ ] 后台概览页面，添加管理按钮，控制各类卡片排序，控制卡片显示与隐藏
[ ] 后台概览页面，支持多种大小规格的卡片（例如1x1, 水平1x2, 2x2等），每个大小的卡片显示内容的丰富度不一样
[ ] 后台概览页面，卡片缺少交互功能，且无法点击进行跳转
[ ] 后台概览页面，带加入卡片：最新文章，最热文章，全站统计信息，快速新建文章

[ ] 后台设置面板下的文章设置中，支持文章详情页中的评论开关功能
[ ] 后台设置面板下的文章设置中，支持文章详情页中的元数据显示开关，单独控制各个元数据

[ ] 后台评论设置中，对于评论的手动审核的按钮没有点击效果，无法判断是否点击
[ ] 后台评论设置中，新增评论的自动审批规则，采用黑名单排除垃圾评论

[ ] 后台文章发布/管理时，支持指定头图，可以通过照片上传或指定url两种方式
[ ] 后台文章发布/管理时，支持直接新增分类和标签
[ ] 后台文章发布/管理时，支持多选文章状态
[ ] 后台文章发布/管理时，支持文章的定时发布功能
[ ] 后台文章发布/管理时，支持定时控制文章状态，例如定时发布，定时过期等等
[ ] 后台文章发布/管理时，slug必填，不允许留空，但是可以通过在输入/修改标题的时候根据标题自动生成slug（中文转化为拼音），并填充进输入框，同时允许用户手动修改slug。此外，slug的唯一性需要在后台进行验证，如果重复，及时在输入框中显示错误提示
[ ] 后台文章发布/管理时，文章保存失败时，保留所有输入框、选择框、单选框、复选框的内容，避免用户重新输入
[ ] 后台文章发布/管理时，保存成功后返回列表页面

[ ] 后台文章编辑页面中，缺少文章内容的实时预览，可以做成分栏形式也可以做成多标签页形式，由用户自行选择
[ ] 后台文章编辑页面中，缺少文章内容的版本管理功能，支持查看历史版本并进行恢复
[ ] 后台文章编辑页面中，缺少文章内容的自动保存功能，避免用户误操作导致内容丢失
[ ] 后台文章编辑页面中，缺少最近保存时间的显示
[ ] 后台文章编辑页面中，缺少未保存时离开的提醒
[ ] 后台文章编辑页面中，对于媒体插入操作复杂，希望可以直接通过复制粘贴图片，自动转化为`![timestamp](url)`的形式插入文本，并且上传媒体
[ ] 后台文章编辑页面中，md编辑时缺少md代码高亮，包括md中涉及到的代码块的高亮

[ ] 后台文章管理中，支持通过标题点击进入编辑页面而非末尾的编辑按钮，且该编辑按钮可以直接删除
[ ] 后台文章管理中，文章列表新增显示字段浏览量、浏览人数、发布时间
[ ] 后台文章管理中，文章列表支持按字段内容进行筛选或排序（具体操作依据字段实际内容决定）
[ ] 后台文章管理中，支持文章的批量操作
[ ] 后台文章管理中，文章列表的状态字段一列作为多选，除显示是否发布的状态以外，还可以同时显示置顶、标记为过期，例如(已发布 置顶 过期)。
[ ] 后台文章管理中，文章slug后添加icon图标，点击即可在新窗口打开文章链接
[ ] 后台文章管理中，支持统一导出和导入文章，支持单个或多个文章导入导出

[ ] 后台管理面板中，推荐将分类和标签两个板块合并

[ ] 后台管理面板中，需要新增统计功能，包括但不限于统计各类文章、分组、标签下的访问人数，访问量，以及收集全部用户的访问行为数据，记录访问时间、访问时长、访问次数、访问内容、来源地区、ip、UA、浏览器指纹、硬件信息、来源url等等。此类内容可以对接数据库，需要在当前数据库结构上进行扩展，或者单独建立一个数据库表来存储这些数据。及时同步相关的设计文档
[ ] 后台统计功能中，支持按日期查看趋势
[ ] 后台统计功能中，支持按文章、分组、标签查看趋势
[ ] 后台统计功能中，建议新增仪表盘，直观展示关键数据
[ ] 后台统计功能中，支持导出全部csv数据
[ ] 后台统计功能中，涉及隐私信息，例如ip、UA、浏览器指纹、硬件信息等，需要在后台设置中提供开关，默认不收集

[ ] 后台管理面板中，需要新增‘个性化’功能，在该功能内进行样式，主题，自定义的修改等等
[ ] 后台个性化功能中，需要添加 Dock 栏、页脚、侧边栏等可自定义。
[ ] 后台个性化功能中，主题切换过于偏向纯css切换，希望可以类似wordpress这类的主题切换
[ ] 后台个性化功能中，新增主题的设置面板，用于调节当前主题的一些可设置选项
[ ] 后台个性化功能中，支持主题预览功能

[ ] 网站整体样式设计中，希望统一组件的风格，默认主题下使用原生样式写的组件
[ ] 网站整体样式设计中，在切换主题的时候希望可以允许导入主题直接使用现成的组件库
[ ] 网站整体样式设计中，规范各个组件的命名，方便主题统一控制样式

[ ] 后台媒体管理中支持设置对象存储配置，默认不启用

[ ] 后台操作中涉及到删除的操作需要确认
